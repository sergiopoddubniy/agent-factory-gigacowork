# /3_sdelka-peregovory

Активируй единственный навык `skills/00-agent-skill/SKILL.md` и выполни
полный workflow, описанный в нём.

## Параметры запуска
Название задачи: Многопараметрические переговоры об условиях перевозки по мандату
Контур: demo
Источник входных данных: спросить
Папка результата: sandbox:/output/3_sdelka-peregovory/
Подтверждённые инструменты: birzha-mcp (average_prices, price_prediction) — только чтение, для якоря. Сторона контрагента (GigaNetwork) — не подключена, только имитация
Дополнительные ограничения: резервная цена берётся только из мандата пользователя, никогда не выводится агентом; ни одна сделка не фиксируется как согласованная без дословного подтверждения пользователя

## Правила выполнения
- **первым сообщением подтвердить источник входных данных**: если в параметрах
  стоит `спросить` либо мандат не приложен — спросить у пользователя мандат
  (якорь, цель, резервная цена, срок, коридоры по 5 измерениям) и не начинать
  переговоры до получения резервной цены;
- если пользователь пишет «как со мной работать» или задаёт вопрос о самом
  агенте — отвечать режимом 0 из SKILL.md (§12), не запускать переговоры;
- исходные документы (мандат) не изменять;
- не выполнять скрытый write-back — реального A2A нет, вся сторона
  контрагента — `SIM_TOOL_CALL`/`SIM_TOOL_RESULT` с `external_write=false`;
- вызовы MCP на чтение (average_prices, price_prediction) выполнять
  по-настоящему, с retry-once при сбое;
- действия с внешним эффектом (финальное согласование сделки) — только после
  `HITL_REQUIRED` и дословного подтверждения пользователя;
- в итоговом ответе показать результат, источники, неопределённости и
  ограничения по формату §8/§17 навыка.
