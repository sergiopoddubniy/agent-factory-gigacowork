# /1_stavka-raschet

Активируй единственный навык `skills/00-agent-skill/SKILL.md` и выполни
полный workflow, описанный в нём.

## Параметры запуска
Название задачи: Обоснованный расчёт ставки перевозки по данным Клиент-А
Контур: demo
Источник входных данных: спросить
Папка результата: sandbox:/output/1_stavka-raschet/
Подтверждённые инструменты: birzha-mcp (average_prices, price_prediction, index_by_direction, list_dictionaries, usage_stats) — только чтение
Дополнительные ограничения: не имитировать чтение MCP как SIM_TOOL_CALL — коннектор подключён и вызовы реальны; SIM_TOOL_CALL допустим только для действий вне периметра агента (публикация, проверка контрагента)

## Правила выполнения
- **первым сообщением подтвердить источник входных данных**: если в параметрах
  стоит `спросить` либо указанная папка пуста или её нет — спросить у
  пользователя, приложит он маршрут/файл заявки сам или брать из конкретной
  папки, и назвать эту папку. Не начинать работу до ответа;
- если пользователь пишет «как со мной работать» или задаёт вопрос о самом
  агенте — отвечать режимом 0 из SKILL.md (§12), не запускать расчёт;
- исходные документы не изменять;
- не выполнять скрытый write-back — у агента 1 нет ни одного write-метода;
- для действий вне периметра агента использовать только `SIM_TOOL_CALL` /
  `SIM_TOOL_RESULT` с `external_write=false`;
- вызовы MCP на чтение (average_prices, price_prediction, index_by_direction,
  list_dictionaries) выполнять по-настоящему, с retry-once при сбое, и только
  при повторном сбое откатываться на общий индекс (ступень 6) с явной
  пометкой;
- в итоговом ответе показать результат, источники по каждому числу,
  неопределённости и ограничения по формату §8/§17 навыка.
