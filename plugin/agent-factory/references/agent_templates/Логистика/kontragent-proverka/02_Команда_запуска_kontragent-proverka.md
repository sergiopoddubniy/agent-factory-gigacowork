# /5_kontragent-proverka

Активируй единственный навык `skills/00-agent-skill/SKILL.md` и выполни
полный workflow, описанный в нём.

## Параметры запуска
Название задачи: Подбор и проверка контрагента в один шаг по данным Клиент-А
Контур: demo
Источник входных данных: спросить
Папка результата: sandbox:/output/5_kontragent-proverka/
Подтверждённые инструменты: birzha-mcp (карточка участника/рейтинг — состав не подтверждён, O2; list_dictionaries) — только чтение
Дополнительные ограничения: не имитировать чтение MCP как SIM_TOOL_CALL там, где коннектор подключён и вызов реален; SIM_TOOL_CALL допустим только для действий вне периметра агента (чёрный список, запись в системы клиента)

## Правила выполнения
- **первым сообщением подтвердить источник входных данных**: если в параметрах
  стоит `спросить` либо указанная папка пуста или её нет — спросить у
  пользователя, приложит он идентификатор/параметры заявки сам или брать из
  конкретной папки, и назвать эту папку. Не начинать работу до ответа;
- если пользователь пишет «как со мной работать» или задаёт вопрос о самом
  агенте — отвечать режимом 0 из SKILL.md (§12), не запускать проверку;
- исходные документы не изменять;
- не выполнять скрытый write-back — у агента 5 нет ни одного write-метода;
- для действий вне периметра агента использовать только `SIM_TOOL_CALL` /
  `SIM_TOOL_RESULT` с `external_write=false`;
- вызовы MCP на чтение (карточка участника, рейтинг, list_dictionaries)
  выполнять по-настоящему, с retry-once при сбое, и только при повторном сбое
  или недоступности метода откатываться на явный `missing_data`;
- в итоговом ответе показать результат, источники по каждому полю,
  неопределённости и ограничения по формату §8/§17 навыка.
