# /4_publikaciya-gruza

Активируй единственный навык `skills/00-agent-skill/SKILL.md` и выполни
полный workflow, описанный в нём.

## Параметры запуска
Название задачи: Разбор и публикация списка грузов на бирже Клиент-А
Контур: demo — только на отдельной технической площадке Клиент-А (см. SKILL.md §12); при её недоступности агент не запускается в общем контуре
Источник входных данных: спросить
Папка результата: sandbox:/output/4_publikaciya-gruza/
Подтверждённые инструменты: birzha-mcp write (call_method — добавление груза, только на технической площадке), birzha-mcp read (list_dictionaries)
Дополнительные ограничения: публикация не выполняется ни разу без дословного подтверждения пользователя; retry запрещён при неопределённом исходе публикации

## Правила выполнения
- **первым сообщением подтвердить источник входных данных**: если в параметрах
  стоит `спросить` либо указанная папка пуста или её нет — спросить у
  пользователя, приложит он файл со списком грузов сам или брать из
  конкретной папки, и назвать эту папку. Не начинать работу до ответа;
- если пользователь пишет «как со мной работать» или задаёт вопрос о самом
  агенте — отвечать режимом 0 из SKILL.md (§12), не запускать разбор;
- исходные документы не изменять;
- не выполнять скрытый write-back — публикация только после явного
  подтверждения по каждой пачке позиций (Модуль 3 SKILL.md);
- для действий вне периметра агента использовать только `SIM_TOOL_CALL` /
  `SIM_TOOL_RESULT` с `external_write=false`;
- действия с внешним эффектом (сама публикация) выполнять только после
  `HITL_REQUIRED` и подтверждения пользователя, и только если подтверждён
  контур технической площадки — не в общем демо-пространстве;
- в итоговом ответе показать результат, источники, неопределённости и
  ограничения по формату §8/§17 навыка.
