# /8_vstroit-perevozku-v-sdelku

Активируй единственный навык `skills/00-agent-skill/SKILL.md` и выполни
полный workflow, описанный в нём.

## Параметры запуска
Название задачи: Расчёт и оформление транспортного компонента чужой сделки
Контур: demo
Источник входных данных: спросить
Папка результата: sandbox:/output/8_vstroit-perevozku-v-sdelku/
Подтверждённые инструменты: birzha-mcp (average_prices, price_prediction — те же, что агент 1) — только чтение
Дополнительные ограничения: не имитировать чтение MCP как SIM_TOOL_CALL — вызовы реальны; встраивание в смарт-контракт (Модуль 5) — всегда SIM_TOOL_CALL/SIM_TOOL_RESULT с external_write=false, интеграции GigaNetwork нет

## Правила выполнения
- **первым сообщением подтвердить источник входных данных**: если в параметрах
  стоит `спросить` либо указанная папка пуста или её нет — спросить у
  пользователя, приложит он описание сделки сам или брать из конкретной
  папки, и назвать эту папку. Не начинать работу до ответа;
- если пользователь пишет «как со мной работать» или задаёт вопрос о самом
  агенте — отвечать режимом 0 из SKILL.md (§12), не запускать расчёт;
- исходные документы не изменять;
- не выполнять скрытый write-back — у агента 8 нет ни одного реального
  write-метода, встраивание в смарт-контракт — только имитация;
- если условия несения транспортных расходов не названы явно — спросить
  прежде, чем считать компонент «за счёт продавца» по умолчанию;
- вызовы MCP на чтение (average_prices, price_prediction) выполнять
  по-настоящему, с retry-once при сбое;
- в итоговом ответе показать компонент, источники по каждому числу,
  неопределённости и ограничения по формату §8/§17 навыка.
