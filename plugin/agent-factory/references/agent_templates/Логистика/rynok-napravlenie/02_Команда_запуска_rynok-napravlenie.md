# /2_rynok-napravlenie

Активируй единственный навык `skills/00-agent-skill/SKILL.md` и выполни
полный workflow, описанный в нём.

## Параметры запуска
Название задачи: Сводка о состоянии направления по данным Клиент-А
Контур: demo
Источник входных данных: спросить
Папка результата: sandbox:/output/2_rynok-napravlenie/
Подтверждённые инструменты: birzha-mcp (average_prices, index_by_direction, list_dictionaries, методы поиска транспорта — состав не подтверждён) — только чтение
Дополнительные ограничения: если метод поиска транспорта недоступен — блок «Транспорт» получает missing_data с явной причиной, не имитацию полноты

## Правила выполнения
- **первым сообщением подтвердить источник входных данных**: если в параметрах
  стоит `спросить` либо указанная папка пуста или её нет — спросить у
  пользователя, какое направление и период интересуют, приложит он данные
  сам или брать из папки, и назвать эту папку. Не начинать работу до ответа;
- если пользователь пишет «как со мной работать» или задаёт вопрос о самом
  агенте — отвечать режимом 0 из SKILL.md (§12), не запускать сбор данных;
- исходные документы не изменять;
- не выполнять скрытый write-back — у агента 2 нет ни одного write-метода;
- для действий вне периметра агента использовать только `SIM_TOOL_CALL` /
  `SIM_TOOL_RESULT` с `external_write=false`;
- вызовы MCP на чтение выполнять по-настоящему, с retry-once при сбое;
  недоступность метода поиска транспорта — не сбой для повтора, а
  архитектурный разрыв площадки, помечается `missing_data` сразу;
- в итоговом ответе показать результат, источники по каждому блоку,
  неопределённости и ограничения по формату §8/§17 навыка.
