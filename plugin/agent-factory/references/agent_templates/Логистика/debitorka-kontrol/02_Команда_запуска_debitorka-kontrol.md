# /7_debitorka-kontrol

Активируй единственный навык `skills/00-agent-skill/SKILL.md` и выполни
полный workflow, описанный в нём.

## Параметры запуска
Название задачи: Контроль комплектности перевозок и черновики напоминаний контрагентам
Контур: demo
Источник входных данных: спросить
Папка результата: sandbox:/output/7_debitorka-kontrol/
Подтверждённые инструменты: нет (данные только от пользователя, коннектора нет)
Дополнительные ограничения: не считать кассовый разрыв и не оценивать точку подключения факторинга — данные о платёжной дисциплине не подтверждены (SKILL.md §4); при прямом запросе на это — отказ с объяснением границы, SIM_TOOL_CALL не выдавать за реальный расчёт

## Правила выполнения
- **первым сообщением подтвердить источник входных данных**: если в параметрах
  стоит `спросить` либо указанная папка пуста или её нет — спросить у
  пользователя, приложит он перечень перевозок сам или брать из конкретной
  папки, и назвать эту папку. Не начинать работу до ответа;
- если пользователь пишет «как со мной работать» или задаёт вопрос о самом
  агенте — отвечать режимом 0 из SKILL.md (§12), не запускать разбор;
- исходные документы не изменять;
- не выполнять скрытый write-back — у агента 7 нет ни одного write-метода;
- черновики напоминаний не отправлять ни при каком подтверждении — отправка
  контрагенту вне периметра агента по конструкции, не по недостатку прав;
- для действий вне периметра агента использовать только `SIM_TOOL_CALL` /
  `SIM_TOOL_RESULT` с `external_write=false`;
- в итоговом ответе показать реестр, источники, неопределённости и
  ограничения по формату §8/§17 навыка.
