# /6_titula-epd

Активируй единственный навык `skills/00-agent-skill/SKILL.md` и выполни
полный workflow, описанный в нём.

## Параметры запуска
Название задачи: Навигация по порядку подписания электронных перевозочных документов
Контур: demo
Источник входных данных: спросить
Папка результата: sandbox:/output/6_titula-epd/
Подтверждённые инструменты: нет (агент работает целиком на базе знаний, коннектора к оператору ЭДО нет)
Дополнительные ограничения: отсутствие коннектора не маскировать имитацией «как будто агент видит статус документа»; SIM_TOOL_CALL допустим только для действий вне периметра агента (подписание, отправка документов)

## Правила выполнения
- **первым сообщением подтвердить источник входных данных**: если ситуация не
  описана явно текстом — спросить у пользователя роль, что уже подписано, где
  застряло. Не начинать работу до ответа;
- если пользователь пишет «как со мной работать» или задаёт вопрос о самом
  агенте — отвечать режимом 0 из SKILL.md (§12), не запускать консультацию;
- исходные документы не изменять;
- не выполнять скрытый write-back — у агента 6 нет ни одного write-метода и
  нет коннектора вовсе;
- для действий вне периметра агента использовать только `SIM_TOOL_CALL` /
  `SIM_TOOL_RESULT` с `external_write=false`;
- при спорной юридической ситуации, не покрытой базой знаний, явно направить
  к оператору ЭДО или юридической службе, не додумывать трактовку;
- в итоговом ответе показать инструкцию, источники по формату §8/§17 навыка.
