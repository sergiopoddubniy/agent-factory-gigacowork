# Инструкция по сборке — Агент № 4, SEO-оптимизация продуктовых страниц

Пошагово, что куда вставить и в каком порядке — вручную, в реальном UI GigaCowork. Комплект пилотный: набор команд пересобран из воркшопного (4 вместо 5 — демонстрационные команды на синтетике убраны, см. `02_Команды_seo-page-optimizer.md`).

## Состав этого комплекта

- `SKILL.md` — источник истины: полная логика агента (модули, источники, критерии, HITL, ограничения). Из него сжаты поля карточки ниже. Дублируется в базу знаний пространства пилота — поле «Инструкция» ссылается на него по имени.
- `01_Агент_seo-page-optimizer.md` — готовые значения для формы «Создание агента»: Название, Описание, Инструкция, рекомендованные Навыки и Коннекторы.
- `02_Команды_seo-page-optimizer.md` — 4 слэш-команды для формы «Создать команду»: Имя, Описание, Инструкции.

## Порядок сборки

1. **Загрузить `SKILL.md` в базу знаний пространства**, в подпапку `4_seo-page-optimizer/` (вместе с остальными справочными файлами агента — они грузятся все сразу для всего пространства, см. `01_Регламент_сопровождения_и_каденция.md`).
2. **Создать агента.** Открыть `01_Агент_seo-page-optimizer.md` и построчно перенести: Название → поле «Название», Описание → поле «Описание», Инструкция (текст целиком, включая обязательный блок активации навыка первыми двумя предложениями — не сокращать и не переставлять) → поле «Инструкция».
3. **Прикрепить навыки и коннекторы** из списка в конце `01_Агент_seo-page-optimizer.md`: Коннектор ДатаРеестр не требуется. Веб-поиск/чтение страниц выдачи — обязательно.
4. **Создать 4 команды.** Слэш-команды в GigaCowork — общий пул на пространство, поэтому имя каждой начинается с номера агента (`4.1`, `4.2` …). Для каждого блока `02_Команды_seo-page-optimizer.md` перенести Имя команды, Описание и Инструкции в форму «Создать команду».
5. **Проверить деплой не из администраторского аккаунта** — по правилу `platform_architecture.md`/`agent_package.md`: попросить одного из пилотных пользователей (не того, кто собирал агента) открыть его и выполнить стартовую команду `4.1`. Если навык не подхватился или команда не видна — пересобрать шаг 1–4, не откладывать проверку до общей демонстрации пилотной группе.

## Статус на старте пилота — что ещё не готово к production

API Яндекс.Метрики у клиента существует, но не интегрировано — автосъём выдачи и A/B-эксперименты недоступны, разбор топ-10 идёт вручную по каждому запуску. Полный чек-лист — раздел 16 `SKILL.md`, сводный статус доступов по всем 7 агентам — `../../06_Карта_доступа_L1-L2-L3.md`.

## Проверка комплекта

Консистентность полей (числа, названия, ссылки команд на файлы базы знаний) проверена скриптом `build_agent_card.py --kb <база знаний агента>` — результат — см. `run_log.md`, раздел «Прогон гипотез / consistency_check».
