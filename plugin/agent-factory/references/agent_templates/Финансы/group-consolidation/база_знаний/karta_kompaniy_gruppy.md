# Карта компаний группы — группа «Клиент-Н»

> ⚠️ СИНТЕТИЧЕСКИЕ ДАННЫЕ. Реквизиты (ИНН, адреса, контакты) — вымышленные,
> не связаны с реальными юридическими лицами или сотрудниками. Названия
> компаний группы использованы иллюстративно, по структуре, аналогичной
> реальному холдингу.

Список компаний группы — **переменный**. На момент подготовки пилота в
комплект входят 4 компании. Агент должен определять состав группы по
факту загруженных комплектов файлов на каждый запуск, а не полагаться на
фиксированное число из этого файла.

| Код | Название (синтетическое) | Роль в группе |
|---|---|---|
| КВ | ООО «Компания В» | Транспортно-логистическая компания группы |
| КА | ООО «Компания А» | Управляющая компания холдинга |
| КБ | ООО «Компания Б» | Торговая компания группы |
| КГ | ООО «Компания Г» | Производственная компания группы |

## Обновление карты

Перед стартом каждого отчётного периода финансовый директор подтверждает
актуальный список компаний группы. Если в загруженном комплекте появляется
компания, отсутствующая в этой карте (или наоборот) — агент фиксирует это
как открытый вопрос, а не решает самостоятельно, включать ли компанию в
периметр консолидации.
