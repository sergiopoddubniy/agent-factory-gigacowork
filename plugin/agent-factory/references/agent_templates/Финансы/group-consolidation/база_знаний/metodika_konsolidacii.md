# Типовые правила элиминации внутригрупповых операций (общая методология)

> ⚠️ СИНТЕТИЧЕСКИЕ ДАННЫЕ. Общая справочная методология, используется агентом
> только тогда, когда правило клиента (pravilo_eliminacii_klienta.md) не
> покрывает конкретную ситуацию.

## Что обычно элиминируется при консолидации группы компаний

1. **Взаимные остатки по расчётам** — дебиторская задолженность одной
   компании группы, соответствующая кредиторской задолженности другой
   (счета 60, 62, 76 и субсчета).
2. **Взаимные займы и проценты по ним** — остаток по счёту 67 (расчёты по
   долгосрочным займам) и 66 (краткосрочным), если заём выдан одной
   компанией группы другой.
3. **Нереализованная прибыль в остатках запасов**, если одна компания
   группы продала товар/услугу другой, и на конец периода эта продукция не
   реализована конечному покупателю (не рассматривается в текущем
   периметре агента — out-of-scope).

## Что обычно НЕ элиминируется

- Обороты, полностью закрытые внутри отчётного периода без остатка на
  конец периода.
- Операции с контрагентами вне периметра группы компаний.
- Курсовые разницы, если у всех компаний группы единая валюта учёта
  (рубль) — в этом случае раздел неприменим.

## Общий принцип проверки

После элиминации сумма актива консолидированного баланса должна быть равна
сумме пассива. Расхождение после элиминации — сигнал ошибки в сопоставлении
пар операций, а не повод скорректировать итоговую цифру вручную без
объяснения.
