## Как агент использует эту таблицу

В режиме «Сравнение периодов» агент сопоставляет текущий свод с этой
таблицей и явно отмечает повторяющиеся расхождения (как остаток по счёту
76.09 выше), а не только разовые отклонения текущего периода.
