# /запустить-агента

Активируй единственный навык `skills/00-agent-skill/SKILL.md` и выполни
полный workflow, описанный в нём.

## Параметры запуска
Название задачи: Консолидация отчётности группы «Клиент-Н»
Контур: <demo | pilot | production>
Входные данные или папка: <sandbox:/... — комплекты «Баланс_<код>.xlsx» +
«Анализ_<код>_внутригрупповые_обороты.xls» по каждой компании группы>
Папка результата: <sandbox:/...>
Подтверждённые инструменты: нет
Дополнительные ограничения: число компаний в комплекте определяется по
факту загруженных файлов, не фиксировано; правило элиминации по умолчанию
см. § 9 навыка

## Правила выполнения
- исходные документы не изменять;
- не выполнять скрытый write-back;
- для demo использовать только `SIM_TOOL_CALL / SIM_TOOL_RESULT`;
- действия с внешним эффектом выполнять только после `HITL_REQUIRED` и
  подтверждения пользователя;
- в итоговом ответе показать результат, источники, неопределённости и
  ограничения.
