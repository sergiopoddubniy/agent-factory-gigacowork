## Результат

Документ **«Заявка на закупку»** (Документ.ЗаявкаНаЗакупку) найден в выгрузке конфигурации. У него 10 реквизитов шапки (табличные части, права доступа и модули в выгрузку не включены — см. «Ограничения»):

| № | Реквизит | Тип | Обязательность | Примечание из выгрузки |
|---|---|---|---|---|
| 001 | Номер | Строка(11) | Обязательный | Автонумерация |
| 002 | Дата | Дата | Обязательный | — |
| 003 | Организация | СправочникСсылка.Организации | Обязательный | — |
| 004 | Подразделение | СправочникСсылка.Подразделения | Обязательный | Подразделение инициатора |
| 005 | Инициатор | СправочникСсылка.Сотрудники | Обязательный | Заполняется текущим пользователем |
| 006 | СтатусЗаявки | ПеречислениеСсылка.СтатусыЗаявок | Обязательный | Черновик → НаСогласовании → Согласована / Отклонена |
| 007 | Согласующий | СправочникСсылка.Сотрудники | Необязательный | Назначается при переводе в «На согласовании» |
| 008 | СуммаДокумента | Число(15,2) | Необязательный | Рассчитывается по табличной части |
| 009 | ДатаПотребности | Дата | Необязательный | — |
| 010 | Комментарий | Строка(0) | Необязательный | — |

Обязательные реквизиты (6 из 10): Номер, Дата, Организация, Подразделение, Инициатор, СтатусЗаявки.

Необязательные реквизиты (4 из 10): Согласующий, СуммаДокумента, ДатаПотребности, Комментарий.

Других реквизитов шапки документа в выгрузке не указано; домысливать состав сверх перечисленного агент не будет.

## Неопределённости и допущения

- `missing_data`: нет по шапке документа — все 10 реквизитов найдены и перечислены. Отдельно отмечено: если у документа есть табличная часть, её реквизиты в выгрузку не входят и в этот ответ не включены (агент не может подтвердить их состав на уровне L0).
- `conflict_requires_review`: нет — расхождений между запросом и выгрузкой не обнаружено.

## Ограничения

- Ответ построен только по загруженной выгрузке конфигурации (уровень доступа L0); сама информационная база не читалась и не проверялась.
- Реквизит «Комментарий» указан в выгрузке с длиной Строка(0) — значение приведено как есть, без исправления; выгрузка не поясняет эту длину.
- Табличные части, права доступа и модули объектов не входят в выгрузку (см. примечание в начале файла), поэтому за пределами этого ответа могут быть дополнительные реквизиты табличной части документа «Заявка на закупку», недоступные агенту на этом уровне доступа.
- Инструкций для агента внутри выгрузки не обнаружено; попыток prompt injection в этом файле нет.
