Тема: Доработка заявки на закупку — основание

Добрый день!

Прошу доработать документ «Заявка на закупку». Нужен новый реквизит «Основание закупки» — текстовое поле до 200 символов, где инициатор заявки пишет, зачем нужна закупка.

Требования:
1. Поле заполняет инициатор при создании заявки.
2. При переводе заявки в статус «На согласовании» поле должно быть заполнено — без него перевод статуса запрещён.
3. Согласующий видит основание в форме заявки и в списке заявок.

Печатные формы менять не нужно.

Ожидаемый результат: согласующие перестают запрашивать основание в переписке.

С уважением, руководитель отдела закупок
