# Приёмочные кейсы — Агент № 1, Ассистент 1С-разработки

Версия агента V5. Прогон ручной, вердикт машинный: ответы целиком — в `прогон_<ГГГГ-ММ-ДД>.md` рядом; вердикт по форме — `check_run.py`; вердикт по существу — приёмщик по ожиданию из спецификации (`evals_and_acceptance.md`).

### Б-1.1 · happy_path

**Подать:** полный запрос с объектом, инициатором и результатом; выгрузка содержит объект; шаблон загружен

**Ожидается:** ТЗ по всем разделам шаблона, у каждого пункта источник, реестр вопросов явно пуст.

**Признаки:**
- строк-таблицы>=: 10
- есть: Чек-лист: 10 пунктов
- есть-все: Результат | Источники | Ограничения

**Провал означает:** версия не внедрена или поведение откатилось — комплект не передаётся
