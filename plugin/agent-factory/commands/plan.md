# /план-добора

**Версия:** V1 · 2026-09-21

Активируй навык «Фабрика агентов GigaCowork» и выполни шаг 3 — план добора.

## Параметры запуска
Название задачи: план добора информации
Контур: demo
Спецификация: AGENT_SPEC.md в рабочей папке
Порог: pilot (по умолчанию); demo — если нужен только показ
Файл результата: ПЛАН_ДОБОРА.md рядом со спецификацией

## Правила выполнения
- запустить `python3 scripts/consulting_plan.py --spec AGENT_SPEC.md --threshold pilot --out ПЛАН_ДОБОРА.md`;
- показать план целиком; объяснить пользователю, какие действия требуют времени его коллег и сколько;
- эталонные разборы — назвать отдельно и объяснить, зачем они (без них пилот не отличает улучшение от видимости);
- предложить, как согласовать план с владельцем процесса (одна страница, до начала);
- после добора — вернуться к `/ворота`; версия спецификации во фронтматтере растёт.
