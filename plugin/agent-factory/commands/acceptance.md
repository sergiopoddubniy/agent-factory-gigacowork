# /приёмка

**Версия:** V1 · 2026-09-21

Активируй навык «Фабрика агентов GigaCowork» и выполни шаг 6 — приёмочный
прогон и пакет доказательств.

## Параметры запуска
Название задачи: приёмочный прогон
Контур: demo
Спецификация: AGENT_SPEC.md; пакет: ./комплект/<id>
Файл прогона: ПРИЁМОЧНЫЙ_ПРОГОН.md по шаблону templates/ПРИЁМОЧНЫЙ_ПРОГОН.template.md
Кто проводит: пользователь, желательно не автор спецификации

## Правила выполнения
- подготовить файл прогона из блока 12 спецификации: по одному разделу `### <id случая>` с полями Вход / Ожидание / Факт / Вердикт;
- пользователь запускает случаи в пространстве агента и диктует факт; вердикт ставится по ожиданию из спецификации, не по впечатлению;
- запустить `python3 scripts/evidence_bundle.py --spec AGENT_SPEC.md --package ./комплект/<id> --acceptance ПРИЁМОЧНЫЙ_ПРОГОН.md --out ./комплект`;
- показать EVIDENCE_BUNDLE.md; каждый FAIL — правка спецификации (блоки 8–12) и пересборка `/собрать`, не правка пакета;
- статус гипотезы результата на этом шаге — «не проверена»; закрытие — `/результат`.
