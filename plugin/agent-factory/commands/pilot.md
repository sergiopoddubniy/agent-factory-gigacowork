# /пилот

**Версия:** V3 · 2026-09-21

Активируй навык «Фабрика агентов GigaCowork» и выполни режим «апгрейд в
пилот» по `references/pipelines/pilot_upgrade.md`.

## Параметры запуска
Название задачи: апгрейд портфеля (или агента) в пилот
Условие входа: воркшоп состоялся и подтверждён клиентом; доступы к реальным системам согласованы; ИБ-ограничения переподтверждены
Корень поставки: существующая поставка; надстройка пилота — `07_Пилот/`

## Правила выполнения
- приращение, а не пересборка: навыки, карточки, команды переиспользуются; пространство пересобирается (`references/workspace_assembly.md`, «Пространство пилота»);
- Этап 1 — апгрейд доступа по чек-листу L0/1→L2→L3 на каждый агент отдельно (§16 навыка, `references/agent_package.md`); Этап 2 — переключение источников с регрессией на калибровке;
- `build_delivery.py --задача пилот` порождает заготовки П1–П13 из спецификации: baseline-форма, регламент и каденция, карты встраивания, реестр метрик, протокол приёмки с блокирующими пунктами вне шкалы, ИБ-соглашение, карта доступа, бэклог, контур улучшения (формы отдаются пустыми), методология и модель эффекта, приёмочные кейсы и файл прогона; заготовки дописываются владельцем процесса;
- Этап 3 — baseline рассылается ДО запуска; уровень оценки, ворота и бейзлайн — по скиллу `feo-ai-methodology`; если его нет в пространстве — сказать прямо и не считать по памяти;
- Этап 2д — приёмочный прогон в пространстве: `check_run.py --кейсы … --прогон …`; Этап 7 — протокол приёмки (`references/pilot_acceptance_protocol.md`) и пакет доказательств `--threshold pilot`;
- чекпойнт одобрения — план управленческого контура; сопровождение — процесс на весь период, реестр метрик живой.
