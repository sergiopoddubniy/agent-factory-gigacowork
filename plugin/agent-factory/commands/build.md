# /собрать

**Версия:** V3.3 · 2026-09-25

Активируй навык «Фабрика агентов GigaCowork» и выполни сборку пакета из
спецификации (Стадия 2 пайплайна одиночного агента, только уровень пакета).

## Параметры запуска
Название задачи: сборка пакета агента
Контур: demo (из фронтматтера спецификации)
Спецификация: AGENT_SPEC.md в рабочей папке
Папка: ./пакет
Версия агента: V1 (при пересборке после правок — следующая: V2, V3 …)

## Правила выполнения
- запустить `python3 scripts/build_agent_package.py --spec AGENT_SPEC.md --out ./пакет --version V<N>`;
- показать вывод аудита дословно; при FAIL — архив не создаётся, и это не обходится: правится спецификация;
- показать пользователю открытые файлы пакета (`SKILL.md`, `run-agent.md`) и объяснить, что править их руками нельзя — следующая сборка перепишет, а аудит увидит несовпадение отпечатка;
- напомнить, что пакет — не комплект: карточка, команды, docx, база знаний, синтетика, точка входа и инструкция по сборке собираются `/комплект` (`references/delivery_composition.md`);
- закончить `/комплект` либо, если нужен только пакет, `/приёмка`.
