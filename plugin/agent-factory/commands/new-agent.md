# /новый-агент

**Версия:** V3.2 · 2026-09-24

Активируй навык «Фабрика агентов GigaCowork» и выполни Стадию 0 пайплайна
одиночного агента — интейк, интервью и черновик спецификации.

## Параметры запуска
Название задачи: новый агент
Контур: demo
Материалы пользователя: спросить (регламенты, примеры документов, письма, описание процесса)
Рабочая папка: спросить; по умолчанию — папка, из которой пользователь запустил команду
Шаблон: templates/AGENT_SPEC.template.md

## Правила выполнения
- первым делом — переиспользование, а не проектирование: `python3 scripts/agent_registry.py --похожие "<джоба>"` и `python3 scripts/templates.py --похожие "<джоба>"`; найденный шаблон берётся папкой и проходится по `КАРТА_ПЕРЕНОСА.md`; исход записать в блок 14;
- назвать уровень агентизации (три вопроса `references/agentization_level.md`) и класс применимости;
- первым сообщением спросить, что уже есть из материалов, и прочитать их до вопросов; материалы получены документом без наблюдения — назвать промежуточность вслух;
- начинать с результата (блоки 1 и 3), не с функций; один вопрос за раз;
- каждый блок в черновике либо заполнен, либо содержит «Допущение: …» или «Не знаем: …» — пустых блоков не оставлять;
- класс применимости выбрать и обосновать одной строкой; для детерминированного — блоки 2 и 4 не требовать;
- закончить запуском ворот (`scripts/spec_readiness.py`, оба порога) и показать вывод дословно;
- блок 14 — исход переиспользования словами «взято» / «не взято — причина» / «кандидатов нет»; блок 6 — подмаркеры «База знаний:» и «Команды:», блок 8 — «Чек-лист полноты:» с критериями «— закрыто, если: …», блок 12 — при возможности «· Признаки: …» для машинной проверки.
