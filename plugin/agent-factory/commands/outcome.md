# /результат

**Версия:** V1 · 2026-09-21

Активируй навык «Фабрика агентов GigaCowork» и выполни шаг 7 — проверку
гипотезы результата.

## Параметры запуска
Название задачи: проверка гипотезы результата
Контур: pilot
Спецификация: AGENT_SPEC.md (порог pilot должен быть пройден); пакет: ./комплект/<id>
Файл прогона: ПРИЁМОЧНЫЙ_ПРОГОН.md — раздел «Гипотеза результата»
Период подтверждения: из блока 3 спецификации

## Правила выполнения
- сверить измерение с блоком 3: та же метрика, тот же бейзлайн, тот же период; опросы участников в расчёт не входят;
- внести в файл прогона `Статус: подтверждена` или `Статус: не подтверждена` и строку «Измерено: …» — «не проверена» после периода подтверждения не допускается;
- если не подтверждена — выполнить «Условие пересмотра» из блока 3: что меняем в спецификации, новая версия S<N+1>;
- запустить `python3 scripts/evidence_bundle.py … --threshold pilot --out ./комплект` и показать блокеры дословно;
- READY по порогу pilot — единственное состояние, в котором агент считается сделанным.
