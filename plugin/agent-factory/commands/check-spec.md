# /ворота

**Версия:** V1 · 2026-09-21

Активируй навык «Фабрика агентов GigaCowork» и выполни шаг 2 — ворота.

## Параметры запуска
Название задачи: проверка спецификации
Контур: demo
Спецификация: AGENT_SPEC.md в рабочей папке (если нет — спросить путь)
Порог: оба (demo и pilot)

## Правила выполнения
- запустить `python3 scripts/spec_readiness.py --spec AGENT_SPEC.md` и то же с `--threshold pilot`;
- показать оба отчёта дословно, включая коды находок и подсказки «→»;
- по каждой находке предложить формулировку правки, но не править спецификацию без подтверждения пользователя;
- если оба порога красные — сразу предложить `/план-добора`;
- вердикт не смягчать: «почти прошло» не существует.
