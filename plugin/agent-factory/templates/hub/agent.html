Проверка

Честная проверка, а не впечатление

Контрольные примерыостаются у вас до конца; увиденный пример становится настроечным, нужен новый
Ваши ответы замороженыФабрика не подгоняет правильные ответы, чтобы прогон прошёл; меняете их только вы
Новый чат без навыковагент работает только по своей инструкции — без подсказок из разговора с Фабрикой
Обязательное — программесроки, деньги и стоп-условия проверяет код: инструкция — совет, код — гарантия
