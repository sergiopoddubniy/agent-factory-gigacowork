# Ассистент 1С-разработки — результат

**Задача:** реквизиты документа «Заявка на закупку» и их обязательность · **Дата:** 2026-09-21 · **Контур:** demo

## Результат

Документ «Заявка на закупку» (Документ.ЗаявкаНаЗакупку) по выгрузке имеет 10 реквизитов.

Обязательные (6):
1. Номер — Строка(11), автонумерация
2. Дата — Дата
3. Организация — СправочникСсылка.Организации
4. Подразделение — СправочникСсылка.Подразделения; подразделение инициатора
5. Инициатор — СправочникСсылка.Сотрудники; заполняется текущим пользователем
6. СтатусЗаявки — ПеречислениеСсылка.СтатусыЗаявок; значения Черновик → НаСогласовании → Согласована / Отклонена

Необязательные (4):
7. Согласующий — СправочникСсылка.Сотрудники; назначается при переводе в «На согласовании»
8. СуммаДокумента — Число(15,2); рассчитывается по табличной части
9. ДатаПотребности — Дата
10. Комментарий — Строка(0)
