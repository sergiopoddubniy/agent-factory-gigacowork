# Регламент подготовки консолидированной отчётности группы «Северный порт»

Утверждён финансовым директором 12.01.2026. Редакция 3. Владелец процесса —
главный бухгалтер АО «Северный порт».

## 1. Периметр консолидации

| Компания | Роль | Доля группы |
|---|---|---|
| АО «Северный порт» | материнская компания | — |
| ООО «Порт-Логистика» | дочерняя | 100 % |
| ООО «Порт-Сервис» | дочерняя | 100 % |

Неконтролирующих долей нет. Периметр меняется только приказом финансового
директора; до приказа любая четвёртая компания в материалах — ошибка
источника, а не расширение периметра.

## 2. Источники данных

1. **Оборотно-сальдовая ведомость (ОСВ)** каждой компании за отчётный
   квартал, выгрузка из 1С в формате `.xlsx`: столбцы «Счет», «Наименование
   счета», сальдо на начало (Дт/Кт), обороты за период (Дт/Кт), сальдо на
   конец (Дт/Кт). Суммы в рублях. Один файл — одна компания.
2. **Реестр внутригрупповых операций (ВГО)** за квартал — готовит отдел
   консолидации по актам сверки. Строка реестра: тип («Расчёты» или
   «Обороты»), компания А (продавец/кредитор), компания Б
   (покупатель/дебитор), сумма по данным А, сумма по данным Б, комментарий.
   «Расчёты» — остаток дебиторской задолженности А к Б (счёт 62 у А) против
   остатка кредиторской задолженности Б перед А (счёт 60 у Б) на конец
   квартала. «Обороты» — выручка А от Б за квартал (счёт 90.01 у А) против
   себестоимости Б по А (счёт 90.02 у Б).
3. **Форма консолидации** `Консолидация_форма.xlsx` — утверждённая форма
   с листами «Ф1» (баланс) и «Ф2» (отчёт о финансовых результатах). Столбцы:
   код, статья, три компании, сумма по группе, корректировки, элиминации,
   консолидировано. Итоговые строки и контроль «актив − пассив» заданы
   формулами формы; формулы не переписываются.

## 4. Внутригрупповые операции

4.1. **Порог существенности расхождения — 50 000 рублей** на одну строку
реестра. Порог установлен финансовым директором и применяется без
изменений до следующей редакции регламента.

4.2. **Расхождение в пределах порога** (|А − Б| ≤ 50 000) считается
неотражённым документом у стороны Б и **дозаписывается у стороны Б** до
элиминации: себестоимость (2120) +δ, кредиторская задолженность (1520) +δ,
нераспределённая прибыль (1370) −δ, где δ = А − Б. Налоговый эффект
корректировки на уровне консолидации не рассчитывается.

4.3. Для одной пары компаний расхождение по «Расчётам» и по «Оборотам»
должно совпадать (один неотражённый документ даёт одну и ту же разницу в
задолженности и в обороте). Если не совпадает — причина не установлена,
консолидация **останавливается** до разбора отделом консолидации.

4.4. **Расхождение больше порога** — консолидация останавливается.
Результат не формируется; отдел консолидации получает перечень строк
реестра с расхождением, парой компаний, суммами обеих сторон и разницей.

4.5. **Элиминация** — по данным стороны А после корректировок: 1230 и 1520
уменьшаются на остаток по «Расчётам», 2110 и 2120 — на оборот по
«Оборотам».

4.6. **Инвестиции.** Финансовые вложения материнской компании (1170)
равны сумме уставных капиталов дочерних (1310) и элиминируются взаимно:
1170 −Σ, 1310 −Σ. Если не равны — консолидация останавливается.

4.7. Корректировки прошлых кварталов не переносятся: реестр каждого
квартала отражает расхождения на его конец, корректировка считается заново.

## 5. Контроли

Все контроли обязаны сойтись, иначе результат не выпускается:

1. ОСВ каждой компании: сумма сальдо Дт = сумме сальдо Кт на конец периода.
2. Ф1 каждой компании: 1600 = 1700.
3. Ф2 каждой компании: 2400 = оборот Кт 99 − оборот Дт 99 за период.
4. Консолидировано: 1600 = 1700.
5. 1230 конс. = Σ1230 − Σ«Расчёты» по данным А; 1520 конс. = Σ1520 + Σδ − Σ«Расчёты» по А.
6. 2110 конс. = Σ2110 − Σ«Обороты» по А; 2120 конс. = Σ2120 + Σδ − Σ«Обороты» по А.
7. 2400 конс. = Σ2400 − Σδ; 1370 конс. = Σ1370 − Σδ.
8. Сумма элиминации по ВГО не превышает статьи, из которой вычитается,
   ни у одной компании.
9. Форма: контроль «актив − пассив» = 0 во всех столбцах.

## 6. Результат квартала

Заполненная форма консолидации (копия утверждённой формы с сохранёнными
формулами), журнал корректировок и элиминаций (по строкам: вид, пара
компаний, содержание, сумма), протокол контролей (по каждому контролю —
ожидание, факт, статус). Суммы — целые рубли, без округления.
