# Журнал версий

## V1 · 2026-09-21

Первая версия. Режим одиночного агента.

- Спецификация агента `AGENT_SPEC.md`: фронтматтер + 15 блоков, статусы
  заполнено / допущение / отсутствует, строки `Допущение:` и `Не знаем:`.
- Скрипты (stdlib, Python 3.9+): `factory_common.py`, `spec_readiness.py`
  (пороги demo/pilot), `consulting_plan.py`, `build_agent_package.py`
  (порождение из спецификации + аудит + детерминированный архив),
  `check_delivery.py` (аудит + сверка отпечатка), `evidence_bundle.py`,
  `selftest.py` (44 проверки, мутации).
- Оркестратор `SKILL.md` (7 шагов), 6 команд, 6 справочников, 2 шаблона.
- Пример `1c-dev-assistant`: спецификация, прогон, план добора, комплект.
- Документы: концепция, архитектура, пилот Пулково, валидация для
  платформы, руководство по внедрению Agent Spec в исходный скилл.

Основание: скилл `gigacowork-agent-scenario` v9.10 (9b8dd938), white paper
AI-DISRUPT PDLC v3.7, практика Spec-Driven Development.
